# C++ Real Implementations

A collection of C++ implementations focused on **data structures, problem solving, and small real-world applications**.

The repository contains implementations built from scratch to practice how data structures work and how they can be used in practical programs.

## Topics Covered

* Linked Lists

  * Singly linked lists
  * Doubly linked lists
  * Circular doubly linked lists
  * Insertion, deletion, traversal, reversal, and rotation
* Hash Tables

  * Separate chaining
  * Insertion, deletion, and searching
* Dynamic data structures
* Pointers and node manipulation
* Structures and data organization
* File input/output
* Basic C++ application development

## Real-World Implementations

Some programs apply these data structures to simple practical systems:

* **Browser History** using a doubly linked list
* **Music Playlist** using a circular doubly linked list
* **Text Editor** using a doubly linked list
* **University Management System** using structures
* **Operating System Simulator** with process management

## Examples

The repository also contains smaller implementations for practicing individual operations, including:

* Adding and deleting linked-list nodes
* Finding the middle element
* Finding the address of a middle element
* Reversing linked lists
* Removing duplicates
* Removing the nth node from the end
* Rotating a linked list
* Traversing circular doubly linked lists
* Hash table operations
* File input/output and sorting

## Technologies

* C++
* Standard C++ libraries
* Console-based programs

## Running the Programs

Most files are standalone C++ programs and can be compiled individually:

```bash
g++ filename.cpp -o program
./program
```

For example:

```bash
g++ Hash_Table_Using_Separate_Chaining.cpp -o hash_table
./hash_table
```

Some programs require user input during execution.

## Purpose

This repository is part of my practical C++ learning and focuses on implementing data structures **from scratch** and applying them to different problems.

Rather than relying only on library implementations, the programs are used to understand how structures such as linked lists and hash tables work internally and how they can be used to build simple applications.
